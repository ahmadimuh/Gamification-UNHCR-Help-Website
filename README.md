# Iran Help Gamification Plugin - WordPress Plugin

This plugin allows you to implement gamification on your WordPress site. The plugin includes various scenarios, educational steps, and user interactions aimed at improving user experience and collecting statistical data about user behavior.

## Features

- Create customizable gamification scenarios
- Ask users for various characteristics (such as age range and gender)
- Collect data from user interactions with scenarios
- Use cookies to save users' progress
- Collect data through Google Analytics for analyzing user behavior
- Respond to user questions and track gamification steps

## Installation and Setup

To install and use this plugin, follow these steps:

1. Download the plugin from the [GitHub Repository](URL_TO_GITHUB).
2. Upload the plugin file to the `wp-content/plugins` directory.
3. Activate the plugin from the WordPress admin dashboard.
4. Configure the plugin via the **Settings** section.
5. Set up the desired gamification scenarios and steps for use.

## Usage

1. After activation, navigate to the **Gamification** section in the WordPress dashboard.
2. Configure various scenarios and set up your educational steps.
3. Once configured, users will automatically interact with the gamification process, and their progress will be saved.

## Using Google Analytics

To collect statistical data, you can use [Google Analytics](https://analytics.google.com). This plugin automatically records events and user interactions in Google Analytics.
